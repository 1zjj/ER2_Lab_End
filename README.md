# ER² Lab 统一工作台

面向学生、教师和管理者的一页式静态前端。真实数据、权限、周报、培训大文件和自动化继续由飞书承载。

## 设计边界

- GitHub只保存公开前端代码、样式、静态目录和飞书入口。
- 不在仓库中保存学生信息、历史周报、项目敏感数据、财务信息、App Secret或模型密钥。
- ZIP、模型、rosbag、视频等大文件保存在飞书云盘或实验室文件存储中。
- 当前为静态预览版，不读取个人实时数据。

## 工作台入口

- GitHub Pages：`https://1zjj.github.io/ER2_Lab_End/`
- `#student`：学生工作台
- `#teacher`：教师工作台
- `#manager`：管理工作台

## 本地检查

使用任意静态HTTP服务器打开仓库根目录即可。不要直接双击`index.html`测试搜索，因为浏览器可能禁止本地文件读取`data/catalog.json`。

## 更新目录

修改`data/catalog.json`可以添加课程、项目、设备和SOP搜索入口。完整内容和大文件不要复制进本仓库，只保存对应飞书链接。
