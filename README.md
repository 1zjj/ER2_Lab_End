# ER² Lab 统一工作台

ER² Lab 面向学生、教师和管理者的一页式飞书工作台。GitHub Pages 负责界面，Cloudflare Worker 负责飞书身份与权限，飞书多维表格负责结构化数据，知识库与云盘负责正文和大文件。

## 本分支实现与上线边界

以下说明代码具备的能力，不代表所有功能均已在生产验收。此次统一修复的发布约定见 [发布说明](docs/unified-release-20260908.md)；实际部署以健康接口中的版本及生产验收结果为准。

- GitHub Pages 已连接生产 Worker，未登录访问会进入飞书 OAuth。
- 已完成页面内周报、历史周报弹窗、共享文献阅读、最近7天文献详情弹窗、表单会话草稿和退出登录。
- 教师可以在当前页查看负责学生的本周周报、近期记录并保存反馈；门户搜索入口可由飞书“门户链接表”动态维护。
- Track A 保留教材入口。课程提交和审核只有在后端课程表及审核人配置齐全时开放；配置未完成时，学习进展填写在统一周报的“学习与方法”中。
- 新成员使用指南只在当前浏览器按登录账号记住阅读进度；可逐项确认、撤销或跳过。完成或跳过后显示学习中心入口，保留“入组说明”。不写入飞书，不变更人员、培训或权限。详见 [指南说明](docs/member-guide.md)。
- Worker 已包含飞书身份与角色校验、写入前成员复核、请求大小限制、重复提交保护、飞书接口超时处理、自动化防重复和定时提醒接口。
- 人员与项目以 90.1 权威表为准。默认配置关闭首次用户引导建档和试点自动登记；新增人员或项目不自动获得项目权限。服务端检查人员状态、有效成员关系、审批、期限、项目状态、保密规则及操作级别，不能以姓名或前端视图代替授权。

## 数据与安全边界

- GitHub 只保存公开前端代码、样式、无内部 URL 的静态搜索索引和 Worker 源码。
- App Secret、Session Secret 只保存在 Cloudflare Secrets。
- 学生信息、历史周报、项目敏感数据和自动化日志保存在飞书。
- ZIP、模型、rosbag、视频和代码包保存在飞书云盘，网页仅保存链接。
- 所有角色和数据范围均由 Worker 服务端校验，不能依赖前端隐藏按钮。

## 本地预览

在仓库根目录运行任意静态服务器：

~~~bash
python3 -m http.server 8080
~~~

然后打开 <http://localhost:8080/>。不要直接双击 index.html，否则浏览器可能禁止读取 data/catalog.json。

## 真实环境启用

1. 按 docs/data-schema.md 映射飞书多维表格字段。
2. 按 docs/feishu-setup.md 创建自建应用并配置权限。
3. 初次接入需配置 Cloudflare Secrets 和 Variables；现有生产环境升级按 [发布说明](docs/unified-release-20260908.md) 执行，先核对绑定再部署，避免使用旧配置覆盖生产。
4. 将根目录 config.js 的 apiBase 改为 Worker 地址，并把 demo 改为 false。
5. 在飞书工作台发布 ER² Lab 应用，完成学生、教师和管理者账号验收。

逐项验收见 [docs/release-checklist.md](docs/release-checklist.md)。

## 版本边界

V1 包含身份识别、个人门户、教师汇总、管理概览、页面内周报、共享文献阅读、提醒和教授汇总。不包含 OpenClaw、跨知识库 AI 问答、大文件代理上传、完整财务系统和完整设备审批。
