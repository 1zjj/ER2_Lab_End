# ER² Lab V1 飞书数据结构

优先复用现有多维表格；字段名不一致时，可改为下列标准字段，或在 worker/src/index.js 的字段映射中增加别名。

## 人员表

| 字段 | 类型 | 说明 |
|---|---|---|
| 姓名 | 文本 | 工作台显示名 |
| 飞书OpenID | 文本 | 唯一身份键，必须唯一 |
| 角色 | 多选 | 学生、教师、管理者；允许多角色 |
| 负责教师OpenID | 文本 | 学生对应教师 |
| 项目编号 | 文本 | 例如 P03 |
| 课程方向 | 文本 | 例如语义导航方向 |
| 是否启用 | 复选框 | 关闭后禁止进入工作台 |

## 周报表

| 字段 | 类型 |
|---|---|
| 飞书OpenID、姓名、周次 | 文本 |
| 周序号 | 数字 |
| 周起始、周结束、提交时间 | 日期或文本 |
| 本周完成与结果、学习与方法、问题与阻塞、下周计划 | 多行文本 |
| 证据链接 | URL |
| 提交状态、审核状态 | 单选 |
| 教师反馈、反馈教师OpenID、反馈时间 | 文本/日期 |
| 请求ID、反馈请求ID | 文本；用于提交和反馈去重 |

飞书OpenID + 周次为业务唯一键。同一学生同一周再次提交时更新原记录。

## 文献阅读表

| 字段 | 类型 |
|---|---|
| 论文标题 | 主字段/文本 |
| 提交人OpenID、提交人姓名、提交人角色、周次 | 文本 |
| 周序号、发表年份 | 数字 |
| 阅读日期、提交时间 | 日期或文本 |
| 作者、会议或期刊、DOI或arXiv、研究方向 | 文本 |
| 阅读类型、提交状态 | 单选或文本 |
| 一句话贡献、核心问题、方法摘要、个人评价、与项目关系 | 多行文本 |
| 论文链接、阅读笔记链接、论文附件链接 | URL |
| 请求ID | 文本；用于网络重试去重 |

所有启用成员可提交和查看。表格、公式与图片写入飞书阅读笔记，PDF及大附件存飞书云盘；工作台只保存并展示链接。同一提交人、同一周次、相同标题和阅读笔记链接视为一次提交，重试会先核对已有记录。文献写入按实时字段类型转换日期和链接，空的选填链接不写入；只有读取到与提交内容一致的记录才返回成功。管理员可在“管理配置 → 数据源诊断”核对当前连接的文献表和字段；诊断入口只读，不自动修改表结构。

## 项目表

项目编号、项目名称、状态、当前里程碑、进度、最近阻塞、飞书链接。

## 课程进度表

Track A 使用纯文字课程记录，不上传图片、视频、PDF、代码包或其他附件。`飞书OpenID + Lesson` 为业务唯一键，学生重新提交时更新原记录。

新成员使用指南的阅读进度只保存在浏览器，不需要为指南创建飞书字段或课程记录。历史 `ONBOARDING` 记录不用于判断新版指南进度，原记录保留。

| 字段 | 类型 | 说明 |
|---|---|---|
| 飞书OpenID、姓名、Track、课程名称、Lesson | 文本 | 学生与课程身份；Lesson 使用 01–10 |
| 核心收获 | 多行文本 | Lesson 01–10 必填 |
| 问题与处理 | 多行文本 | Lesson 01–10 必填；无问题时填写“无” |
| 课程总结 | 多行文本 | 仅 Lesson 10 必填 |
| 其他 | 多行文本 | 选填 |
| 状态 | 单选或文本 | 等待朱俊杰确认、需要补充、朱俊杰已确认 |
| 提交时间、确认时间、课程完成时间 | 日期或文本 | 由 Worker 写入 |
| 确认说明、确认人、确认人OpenID | 文本 | 朱俊杰确认或要求补充 |
| 请求ID | 文本 | 用于提交去重 |
| 结业状态 | 单选或文本 | Lesson 10 用于保存 Track A 完成状态 |
| 结业通知状态 | 单选或文本 | 待配置、发送中、已发送、发送失败 |
| 结业通知时间、结业通知消息ID、结业通知尝试ID | 日期或文本 | 记录唯一通知尝试并防止重复通知教授 |

### 新成员使用指南

五项说明为认识工作台、阅读实验室规则、查看环境准备说明、了解学习安排、了解周报填写方法。每项可确认或撤销，也可跳过指南进入学习中心。

阅读状态不代表正式入组、培训通过或权限批准。“人员状态”“入组时间”“保密等级”“培训状态”“系统职责”等仍按 90.1 权威人员表及管理员维护的规则处理；项目访问仍受后端授权限制。新版指南不调用 `/api/onboarding`，不写人员表、课程表、周报表或自动化日志。浏览器按后端确认的账号隔离阅读进度，换浏览器或清理网站数据后可重新出现。详见 [指南说明](member-guide.md)。

### 课程记录权限

学生只能从 API 读取和修改自己的记录；朱俊杰可以查看全部记录并确认；陈铮一教授可以查看全部记录但不能执行确认。权限由 Worker 根据飞书 `open_id` 强制校验，不能只依赖前端隐藏。生产环境必须配置两人的精确 OpenID；缺失时课程审核和教授全量查看均保持关闭。

## 任务表

飞书OpenID、任务名称、任务说明、类型、截止时间、状态。

## 门户链接表

标题、链接、分类、副标题、关键词、可见角色、排序、是否启用。可见角色使用学生、教师或管理者；前端搜索目录由此表动态生成。

## 自动化日志表

运行键、任务名称、执行时间、执行结果、执行说明。运行键在同一周同一任务中必须唯一，用来防止定时任务重复发送。

## 大文件规则

培训代码包、模型、视频、rosbag、论文附件和数据集不得上传 GitHub，也不得经过 Worker。上传飞书云盘后，在课程、项目、任务或文献阅读表中保存链接。
