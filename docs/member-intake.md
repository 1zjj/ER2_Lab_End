# 成员入组入口（第一阶段）

位置：管理配置 → 成员与权限 → 成员入组。

本阶段仅准备方案、下载本地 JSON 待完善资料、检查条件；没有正式创建、云端草稿、自动邀请、应用范围修改、知识库授权或权限迁移。下载文件含人员信息，须由管理员妥善保管。关闭窗口前提示资料丢失。

必填：模板、姓名、账号/显示名、人员边界、成员类别、组织状态、开始日期、功能选择；要求周报时必须填写起始周周一。到期日、意向项目、备注可空白。组织状态为自报，不能当作验证通过。

POST /api/admin/member-intake/check 每次从正式人员表重新核验身份和管理员职责，只读检查，不写入。姓名或显示名不得自动关联唯一身份；仅当前表唯一匹配的 OpenID 与姓名一致时报告已有匹配。仍不认定组织、应用或原生文档授权已完成。

新功能不触碰既有成员边界、任务、功能授权、财务职责和项目关系，也不接管学生现有 /api/onboarding 流程。

测试：cd worker && node member-intake.test.mjs。上线需同时部署 Worker 和前端；前端没有匹配后端时保留表单并提示失败，绝不显示已开通。
