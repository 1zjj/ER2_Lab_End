# 每周私人草稿与图文周报

本次以稳定性修复为基础合并 P-007/P-008 的已批准参与规则，不改人员记录、全局角色、项目关系、财务或学习权限。飞书原生应用可用范围需要单独添加；代码中的功能资格不等于平台入口授权。

## 数据位置

- 草稿文字、随手记录、版本与图片：使用现有 SQLite Durable Object 命名空间内独立的、按周报来源与账号隔离的对象。对象键带 `private-weekly-draft-v1` 前缀，与正式提交 journal、文献、学习、财务和权限同步对象隔离。不新增公开图片域名。
- 图片限制 10 张/份、2MB/压缩后单张；上传前浏览器压缩，后端仅接收有界 PNG/JPEG 栅格并剥离元数据；输入可选 JPG/PNG/WebP。私有字节以 64KiB 分块存储，ready 标记最后写入。
- 图片每人初版最多 1000 个唯一文件，达到后明确拒绝上传并要求扩容，不自动删除旧图片。
- 本机 IndexedDB 保存未同步内容及冲突/表单副本，按账号隔离。未同步内容退出前提示；网络失败不会宣称云端已保存。
- 正式文本继续在唯一飞书周报表。新增文本字段“周报图文”仅保存图片引用/说明，不写 base64 或公开地址。

## 周次与版本

- 打开“本周草稿本”由服务器选择上海时区当前周；首次输入后才创建草稿，不批量生成空本。
- 上周草稿保留，超出本周/前一周窗口后只读，不自动迁移内容或突破补交限制。
- 日常记录、尚未点“添加”的随手文字、五项正文及图片引用均可保存。保存不影响正式提交状态、提醒和教师统计。
- 保存使用 baseRevision 与请求回执；冲突不覆盖，本机副本可查看。历史草稿可分页访问、导出文字。当前实现保留所有云端版本和已提交快照，不自动清理。
- 表单文本本机自动保存；确认云端基线后自动同步。云端与当前表单已有不同内容时要求用户载入或另存为新版本，不静默覆盖。

## 图片权限与正式提交

- 私人草稿仅本人可读，教授不能读取未提交草稿。
- 其他账号取图必须是当前指定周报审核人，且当前正式记录的 owner、请求ID、图片清单匹配。任何客户端传入的已审核标记均被服务端覆盖。
- 仅留在草稿的图片不随表单提交；正式结果只包括用户选入成果/问题的图片。
- 正式写入前校验图片归属和完成状态；读回校验图片清单。请求回执保留旧 text hash 格式，同时增加可选 imageHash，使图片变更进入幂等校验并保持旧 journal 可核对。
- 删除草稿内引用不会删除图片文件或旧提交快照；不存在真实数据删除接口。

## 发布核验

- 开关 `WEEKLY_DRAFTS_ENABLED` 控制新入口。
- 健康检查确认私有草稿对象版本及周报图文字段兼容，发布失败沿用既有回退流程。
- 测试覆盖本机自动保存、云端冲突、按周隔离、草稿隐私、图片类型与归属、正式图文幂等、SQLite 实际字节读回及其他业务回归。所有写入测试使用合成数据或隔离存储，不写真实周报、不发送通知。
