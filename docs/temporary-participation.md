# P-007 / P-008 临时参与规则

用户批准两位团队内临时成员自 2026-09-14 这一周开始提交周报；文献允许阅读及自愿分享，不要求每周三篇，不显示欠交或完成率。不分配项目，不扩大其他功能，不删除任何记录。

配置 `TEMPORARY_WEEKLY_VOLUNTARY_READING_PERSON_IDS=P-007,P-008`。参与者仍必须通过正式人员身份校验，并同时满足团队内、临时、在组、启用、未离组；身份读取继续校验唯一绑定及到期状态。两人不改为 student 或 manager 角色，不修改全局 isInternalMember 判定。

- 周报资格、提醒和教授汇总使用同一份 opt-in 判定；起始周单独配置为 2026-09-14。
- 原有六位成员保持原有配置；其他临时成员不自动加入。
- 文献权限与任务要求分离：canSubmit=true、targetRequired=false、minimum=0、completed=null。
- 自愿分享正常作为共享阅读记录展示；总分享篇数是描述性统计，不是提交目标或完成率。
- 不改变学习、组会、项目、财务和后台权限。不给两人创建项目关系。
- 飞书原生权限、人员记录及应用可用范围不由此代码修改。

验证：`weekly-backfill.test.mjs` 使用模拟人员及模拟远端请求检查两人提交周报、自愿分享、起始周、其他人员不变及离组后拒绝；`temporary-participation.test.mjs` 检查 opt-in 隔离和前端不显示篇数目标。全部测试不得写真实数据或发送消息。

后续取消资格：从专用配置移除对应编号即可撤销本次额外能力；独立的人员停用/到期校验仍生效。若成员转正，其权限按原有正式成员规则处理，需要另行确认周报与文献要求。
