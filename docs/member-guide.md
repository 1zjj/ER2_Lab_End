# 新成员使用指南

该模块为使用说明。管理员在 90.1 人员表维护正式人员状态，指南的阅读或跳过不代表入组审批、培训完成或项目授权。

| 说明 | 内容 |
|---|---|
| 认识工作台 | 学习中心、周报和文献阅读入口 |
| 阅读实验室规则 | 安全、保密、文件规范；具体要求以正式规则和 SOP 为准 |
| 查看环境准备说明 | 按课程准备系统、软件和代码，遇错联系课程负责人 |
| 了解学习安排 | 课程顺序、学习记录和实际审核 |
| 了解周报填写方法 | 五项周报内容、提交时间、本人历史和教师反馈；无需测试提交 |

每项显示“我已了解”。确认只更新该项，已确认项目可撤销。全部确认后，首页显示“学习中心”，并保留“入组说明”。“已熟悉，直接进入学习中心”会记住跳过选择，但不会把五项设为已了解。指南未完成也可以进入学习中心。

## 阅读进度

`guide-store.js` 使用当前浏览器的 localStorage，并以 API 环境和后端确认的账号标识分区。仅保存五个布尔值和一个跳过值，不保存会话令牌或业务内容。未绑定账号时不允许读写；切换账号不会共用进度。撤销项目也会清除跳过选择，首页恢复指南提示。

每项单独保存，避免不同标签页更新不同项目时互相覆盖。网站存储被禁用时，仅在本次页面内记住进度，并明确提示刷新后可能重置。清除网站数据、使用其他浏览器或设备会重新出现指南。该进度不得用于鉴权。

## 数据与知识库边界

指南不调用 `/api/onboarding`，不创建或修改飞书人员、培训、周报或日志记录，也不触发入组任务。90.1 正式入组管理、90.3 培训记录、项目成员关系和原生飞书权限独立维护。现有知识库规则与课程正文保持原位置。本次不创建五个进度字段，也不更改“新人入组”自动化。

指南内“查看周报表单”只打开已有表单；用户填写并提交后，才走现有正式周报流程。学习中心里的课程记录提交仍依赖原有后端配置和权限，指南本身不会开启尚未配置的课程写入。

## 发布与验证

这项变更只需 GitHub Pages 发布，Worker 无需重新部署。Pages 必须包含 `guide-store.js`，并在 `app.js` 之前加载。主页增强脚本使用同一次已鉴权的 dashboard 结果，不再用独立请求或观察自身 DOM 变化来反复重绘。

运行 `node tests/member-guide.test.mjs` 和 `node tests/weekly-ui.test.mjs`。线上验证单项确认、撤销、刷新保留、跳过、全项完成和重新查看说明；不需要生成测试周报或课程记录。
